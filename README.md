# Data Structures & Algorithms — Personal Reference Notes

A personal reference tutorial for DSA concepts written in plain English with real-life analogies, flow diagrams, and code examples in both Python and C++.

---

## Structure

```
assets/
  images/                         # Diagrams and images used in notes

01_introduction_and_complexity/   # DSA foundations and analysis
02_arrays/                        # Array patterns and range-query techniques
03_strings/                       # String processing and matching
04_recursion_and_backtracking/   # Recursive thinking and constraint search
05_sorting_algorithms/            # Comparison and non-comparison sorting
06_searching_techniques/          # Linear, binary, rotated-array and ternary search
07_linked_lists/                  # Linked-list operations and pointer techniques
08_stacks_and_queues/             # Stacks, queues, deques and monotonic structures
09_hashing/                       # Hash maps, collisions and frequency patterns
10_trees/                         # Tree traversal and common tree problems
11_binary_search_trees/           # BST operations and validation
12_heaps/                         # Priority queues and top-k problems
13_graphs/                        # Graph representations, traversal and shortest paths
14_greedy_algorithms/             # Greedy choice and proof-oriented problems
15_dynamic_programming/           # Memoization, tabulation and classic DP
16_trie_data_structure/           # Prefix trees and prefix queries
17_bit_manipulation/              # Bitwise operators and binary techniques
```

---

## Format

Every file follows the same format:

- Plain English explanation with real-life analogies
- Mermaid flow diagrams and ASCII visuals
- Step-by-step traces and comparison tables
- Python code with inline comments
- C++ code with inline comments
